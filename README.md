## 📋 نبذة عن المشروع

**قرطاسية وهج** هي منصة تجارة إلكترونية متكاملة موجهة للعملاء في الخرطوم، السودان. تقدم الموقع خدماتًا شاملة تشمل:

- 🎁 **توفير المنتجات**: أدوات مدرسية وقرطاسية عالية الجودة
- 🖨️ **خدمات الطباعة**: طباعة ملونة وتغليف احترافي للبحوث
- 👥 **خدمات B2C و B2B**: للأفراد والطلاب والشركات
- 📱 **نظام طلب بسيط**: عبر الواتساب مع واجهة سهلة الاستخدام

## 🎯 المميزات الرئيسية

✅ **تصميم ريسبونسف** - متوافق مع جميع الأجهزة

## 📱 الميزات التفصيلية

### 1. **النافيجيشن (Navigation)**
- شريط تنقل ثابت (sticky)
- روابط سريعة للأقسام الرئيسية
- عداد سلة التسوق

### 2. **قسم البطل (Hero Section)**
- خلفية متدرجة مع صورة
- نص ترحيبي جذاب
- أزرار الدعوة للعمل (CTA)

### 3. **قسم المنتجات (Products)**
- عرض شبكي للمنتجات
- صور من Unsplash
- أزرار الإضافة للسلة
- معلومات السعر والتوفر

### 4. **سلة التسوق (Cart)**
- سايدبار منزلق
- عرض وحذف المنتجات
- حساب الإجمالي التلقائي
- نموذج بيانات العميل

### 5. **نظام الدفع (Checkout)**
- إدخال بيانات العميل
- التحقق من صحة البيانات
- إرسال الطلب عبر WhatsApp API
- رسائل التأكيد (Toast)

### 6. **بيانات التواصل (Contact)**
- أرقام الهاتف المباشرة
- خريطة Google Embed
- معلومات الموقع

## 📊 دوال جافا سكريبت الرئيسية

| الدالة | الوصف |
|-------|-------|
| `toggleCart()` | فتح/إغلاق سايدبار السلة |
| `addToCart(name, price)` | إضافة منتج للسلة |
| `removeFromCart(index)` | إزالة منتج من السلة |
| `updateCartUI()` | تحديث واجهة السلة |
| `sendToWhatsApp()` | إرسال الطلب عبر الواتساب |
| `showToast(msg)` | عرض رسالة تنبيه |
| `validateCustomerData()` | التحقق من بيانات العميل |

## 🎨 تخصيص المشروع

### تغيير الألوان
في `index.html` أضف في الـ Tailwind script:
```javascript
tailwind.config = {
    theme: {
        extend: {
            colors: {
                customColor: '#ABC123'
            }
        }
    }
}
```

### تغيير رقم الواتساب
في `script.js`:
```javascript
const WHATSAPP_NUMBER = "YOUR_PHONE_NUMBER";
```

### إضافة منتجات جديدة
في `index.html` كرر الكود التالي:
```html
<div class="bg-white p-5 rounded-[2.5rem] shadow-sm ...">
    <img src="YOUR_IMAGE_URL" alt="Product Name">
    <h3>اسم المنتج</h3>
    <button onclick="addToCart('Product Name', 1500)">إضافة</button>
</div>
```

## 🐛 حل المشاكل الشائعة

### المشكلة: الصور لا تظهر
**الحل:** تأكد من وجود اتصال إنترنت، حيث أن الصور من خدمات خارجية

### المشكلة: الواتساب لا يفتح
**الحل:** 
1. جرب من هاتف ذكي (يحتاج تطبيق الواتساب)
2. تحقق من رقم الهاتف في `script.js`

### المشكلة: الموقع لا يبدو صحيحًا على الهاتف
**الحل:** قم بـ Hard Refresh (Ctrl+Shift+R)
